# Simple autonomous email agent 

Based on the [substack tutorial](https://niharikabatra.substack.com/s/16-week-aiml-series) by Niharika Batra

[Github Link](https://github.com/niharika2309/autonomous-agent)

Agent = Model + Harness — the model decides what to do next (reason → act → observe), the harness runs the loop, executes tools, and enforces limits.

## UI
Implemented using gradio 

### Setup
pip install gradio

### Run
python app.py
